# 2026-10-28 — The MP210 on the desk: the self-test, the code page, the first tickets

The MP210 (`DC:0D:51:92:74:DA`) paired with the laptop (lapG7) and printing from it over RFCOMM
channel 1. Paper only: no fish motors, no board. Branch `sorting-hat`; the code page strip at
`fca1eb9`, the sample ticket at `dc94e54`.

## Pairing on the laptop

```
rfkill unblock bluetooth && bluetoothctl power on
bluetoothctl: agent on, default-agent, pair DC:0D:51:92:74:DA (PIN 0000), trust DC:0D:51:92:74:DA
bluetoothctl info DC:0D:51:92:74:DA
wpctl status | grep -i bluez
```

| Fact | Value |
|---|---|
| Pairing | Paired, bonded, trusted; no sudo |
| Class / icon | `0x00040680`, printer |
| UUIDs | Serial Port `00001101`, RFCOMM, SDP, L2CAP, PnP, `000018f0`, `e7810a71-…`, `ffcacade-…` |
| Audio | No Audio Sink `0000110b`; `wpctl status` shows no `bluez` sink |

## The code page strip

```
for cp in 2 19 16; do
  .venv/bin/python tools/printer_check.py send --mac DC:0D:51:92:74:DA --codepage $cp \
      --text "t=$cp: ñÑ áéíóú ü ¿Qué? ¡Sí!" --feed 1
done
.venv/bin/python tools/printer_check.py send --mac DC:0D:51:92:74:DA 1B40 --encoding cp850 \
    --text "default cp850: ñ á é ¿ ¡" --feed 4
```

Each `--codepage` run starts `1B 40 1C 2E 1B 52 00 1B 74 n`.

| `ESC t` | Codec sent | On paper | Connect |
|---|---|---|---|
| 2 | cp850 | ñÑ áéíóú ü ¿Qué? ¡Sí! — right | 0.37 s |
| **19** | cp858 | ñÑ áéíóú ü ¿Qué? ¡Sí! — right | 0.29 s |
| 16 | cp1252 | black blocks for every byte over 0x7F | 0.28 s |
| none (`ESC @` only) | cp850 | ñ á é ¿ ¡ — right | 0.33 s |

So: **16 is not cp1252 on this firmware**; `ESC t 19` with cp858 (what `ticket.py` sends) is
right, and so is the power-on default, CP850. Curly quotes, dashes and "…" stay mapped by
`printable()`.

